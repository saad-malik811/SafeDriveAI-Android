# SafeDrive AI – Android Application

An AI-powered Android application designed to monitor driver alertness and help identify signs of drowsiness using computer vision.

## Overview

SafeDrive AI is a native Android application developed using Kotlin, CameraX, and Google's MediaPipe Vision Tasks. It uses the device camera for driver monitoring and provides an interface for monitoring sessions, settings, summaries, and session history.

## Features

- Camera-based driver monitoring
- Computer vision integration using MediaPipe
- Dedicated monitoring interface
- Monitoring settings
- Session summaries
- Session history
- Native Android user interface

## Technologies Used

- Kotlin
- Android Studio
- Android SDK
- CameraX
- Google MediaPipe Tasks Vision
- SQLite / local data storage 
- XML layouts
- Gradle

## Installation

1. Download the APK from the Releases section.
2. Transfer the APK to your Android device.
3. Install the application. You may need to allow installation from your chosen file source.
4. Grant camera permission when prompted.
